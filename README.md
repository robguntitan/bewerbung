# Modernes Bewerbungs‑Template (HTML)

Diese Vorlage ist ein einfach editierbares, responsives HTML‑Template für eine Bewerbung / Lebenslauf mit Schwerpunkt Full‑Stack Entwicklung und KI‑Integration.

Dateien
- `index.html` — Haupttemplate (Inhalte anpassen: Name, Kontakt, Experience, Education, Projects)
- `assets/styles.css` — Styles (Light/Dark, Druckoptimierung)
- `assets/script.js` — Kleines JS für Theme‑Toggle und E‑Mail kopieren

Anleitung
- Öffne `index.html` in einem Browser oder hoste die Datei lokal, um das Ergebnis anzusehen.
- Ersetze die Platzhalter (Name, E‑Mail, Stationen) mit Deinen Daten.
- Die Sektion "Ausbildung" enthält Beispielstationen — ändere sie nach Bedarf.

Anpassungstipps
- Skills: Ergänze oder entferne Einträge in der Liste mit Deinen Technologien.
- Experience: Kopiere die `article.job`-Blöcke und passe Firma, Zeitraum und Bullet‑Points an.
- Projekte: Füge Links zu Repositories oder Live‑Demos hinzu.

Design‑Hinweise
- Das Template ist responsiv und druckoptimiert — für Bewerbungen als PDF: "Drucken" im Browser → als PDF speichern.
- Dark Mode wird lokal gespeichert (localStorage).

Lizenz
Du darfst die Vorlage frei für Bewerbungen verwenden und anpassen.

Viel Erfolg bei Deiner Bewerbung!
