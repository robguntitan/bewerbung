### Schwerpunkt KI-Integration & KI-gestützte Nutzeranwendungen

Anleitung
- Öffne `index.html` in einem Browser oder hoste die Datei lokal, um das Ergebnis anzusehen.
- Ersetze die Platzhalter (Name, E‑Mail, Stationen) mit Deinen Daten.
- Die Sektion "Ausbildung" enthält Beispielstationen — ändere sie nach Bedarf.

Design‑Hinweise
- Das Template ist responsiv und druckoptimiert — für Bewerbungen als PDF: "Drucken" im Browser → als PDF speichern.
- Dark Mode wird lokal gespeichert (localStorage).
